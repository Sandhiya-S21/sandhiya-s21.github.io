About me

Building useful things with code

I’m a Computer Science graduate (B.Sc., SASTRA University, 2026) who enjoys turning raw data into something useful. My main project is a real-time traffic monitoring system built with Python, OpenCV and YOLOv11. It detects and segments vehicles in video, analyses traffic density and predicts signal timing with a regression model. Alongside computer vision, I work with SQL, Java and the MERN stack, and I like building small tools that solve real problems. I’m looking for an entry-level Software Developer or Data Analyst role where I can keep learning and contribute from day one. Based in Mayiladuthurai, Tamil Nadu.
